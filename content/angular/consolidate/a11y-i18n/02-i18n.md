## Hai cách

| | Angular i18n (`i18n`, `$localize`) | Thư viện runtime (Transloco, ngx-translate) |
|---|---|---|
| Dịch lúc | **Build** — mỗi ngôn ngữ một bản build | **Runtime** — tải file JSON theo ngôn ngữ |
| Đổi ngôn ngữ | Tải lại sang bản build khác (`/vi/`, `/en/`) | Ngay lập tức, không reload |
| Hiệu năng | Tốt nhất (chuỗi đã nằm sẵn trong code) | Thêm chi phí tra cứu, tải file |
| Quy trình | Trích xuất `ng extract-i18n` → file XLIFF → dịch | Quản lý key trong JSON |

```html title="Angular i18n"
<h1 i18n="@@caseListTitle">Danh sách hồ sơ</h1>
<p i18n>Có {count, plural, =0 {không hồ sơ nào} =1 {một hồ sơ} other {{{count}} hồ sơ}}</p>
```

```ts
const msg = $localize`:@@saved:Đã lưu hồ sơ ${code}:code:`;
```

## Định dạng theo locale

Ngày, số, tiền dùng pipe (`date`, `number`, `currency`) với `LOCALE_ID` — không tự ghép chuỗi:

```ts
registerLocaleData(localeVi);
providers: [{ provide: LOCALE_ID, useValue: 'vi' }];
```

:::quiz Cổng thông tin cần đổi ngôn ngữ Việt ↔ Anh ngay lập tức, không tải lại trang. Chọn?
- [ ] Angular i18n build-time
- [x] Thư viện runtime (Transloco / ngx-translate)
- [ ] Không làm được trong Angular
- [ ] Dùng Google Translate

Angular i18n chuẩn tạo bản build riêng cho mỗi locale — đổi ngôn ngữ nghĩa là chuyển sang bản build khác.
:::
